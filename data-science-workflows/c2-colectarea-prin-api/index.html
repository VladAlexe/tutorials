Lecția 2 din 8

Colectarea datelor prin API

Până acum datele au provenit dintr-un fișier primit. De la această lecție provin dintr-o cerere scrisă: ce este un API, cum arată un mesaj HTTP, cum se citește un răspuns și cum se aduc primele date reale.

Lecția se deschide după ce este predată la curs. Până atunci, descrierea de mai jos rămâne disponibilă.

Despre lecție

Lecția tratează proveniența datelor: o analiză poate fi verificată doar dacă drumul de la sursă la tabel poate fi refăcut. La cursul 1, datele au provenit dintr-un fișier descărcat în prealabil; de la această lecție provin dintr-o cerere scrisă, care conține sursa, setul și filtrele.

Lecția începe cu ce este un API și de ce se colectează date prin el, trece prin tipurile și istoria API-urilor, apoi analizează o cerere element cu element: adresa, cu endpoint-ul și parametrii, mesajul HTTP, metoda și codul de stare. Aceeași cerere se scrie apoi în Python, cu requests, iar la final ideea se aplică la Eurostat, care trimite un tabel cu mai multe dimensiuni pe un singur rând, pe datele migrației.

Ora se încheie cu formarea echipelor de proiect, pe site.

Obiectivele lecției

  • API-ul ca acces la datele unui furnizor, după reguli publicate: abstractizarea, versionarea și lipsa stării.
  • Motivele colectării prin API și situațiile în care un fișier publicat, datat și versionat este suficient.
  • Stilurile REST, GraphQL, gRPC și SOAP și criteriile după care se clasifică API-urile.
  • Citirea unui mesaj HTTP: prima linie, antetele, corpul.
  • Alegerea metodei HTTP potrivite și motivul pentru care o cerere GET se poate relua fără riscuri.
  • Componentele unei adrese (adresa de bază, endpoint-ul, parametrii) și legătura dintre parametri și dicționarul params din requests.
  • Clasa unui cod de stare și verificarea corpului după cod.
  • O cerere cu requests: citirea răspunsului și gestionarea paginării.
  • Citirea unui răspuns Eurostat: valorile numerotate, potrivite cu regiunile, devin un tabel.

Pregătire

Lecția poate fi urmărită fără programe instalate. Partea practică necesită mediul de la cursul 1 și caietul lecției:

  1. Folderul dsw de la cursul 1, cu mediul .venv. requests este deja instalat, din requirements.txt.
  2. Caietul 02_colectarea_datelor_prin_api.ipynb: pe pagina lui de pe GitHub se apasă Download raw file, iar fișierul se salvează în dsw/curs/, lângă caietul 01. Arhiva întreagă nu se descarcă din nou peste dsw, deoarece poate suprascrie caietele completate.
  3. Kernelul .venv, ales în VS Code: Select Kernel → Python Environments → .venv. Dacă lista nu oferă nicio sursă, VS Code propune în aceeași fereastră extensiile Python și Jupyter.

Datele lecției nu se descarcă manual: sunt obținute prin API și se salvează în dsw/curs/data/c2/. Nu este necesară o cheie de acces, deoarece API-urile folosite sunt publice. Pentru ca răspunsurile să fie salvate și incluse în progresul grupei, autentificarea se face cu GitHub.
