Un API funcționează ca un restaurant

Clientul nu intră în bucătărie: comandă din meniu, prin ospătar.

Banca Mondială mută datele pe alt server și schimbă baza de date, dar păstrează adresele și parametrii din documentație. Ce se întâmplă cu scriptul de colectare?

Scriptul depinde de contract (adrese, parametri, formatul răspunsului), nu de felul în care e construit serverul. Documentația, nu infrastructura furnizorului, e ce trebuie urmărit.

De ce prin API

Un fișier se descarcă dintr-un clic. De ce o cerere scrisă?

1

Proveniența

Cererea arată sursa, setul și filtrele. Oricine o poate rula din nou.

2

Scara

Mii de valori, pe regiuni și pe ani, într-o singură buclă.

3

Calitatea

Fără copieri manuale: unitățile și metadatele vin odată cu valoarea.

Costul: dependența de furnizor. Un fișier publicat și versionat, ca SCI de pe HDX, rămâne o alegere bună.

Aceeași întrebare, patru stiluri

Populația României în 2024, cerută în fiecare stil.

REST

o resursă la o adresă; forma răspunsului o decide serverul

GET /v2/country/RO/indicator/SP.POP.TOTL?date=2024

GraphQL

o interogare; forma răspunsului o decide clientul

{ country(code: "RO") { population(year: 2024) } }

gRPC

o funcție la distanță; forma o fixează contractul

Populatie({tara: "RO", an: 2024})

SOAP

un mesaj XML; forma o fixează contractul

<Populatie><tara>RO</tara><an>2024</an></Populatie>

Doar exemplul REST este un API real, al Băncii Mondiale; celelalte arată forma aceleiași cereri.

Ce este un endpoint

Adresa la care se cere o anumită resursă. Fiecare endpoint întoarce altceva.

Adresa de bazăhttps://api.worldbank.org/v2

Endpoint-ulCe întoarce

Aceeași adresă de bază, trei resurse diferite. Documentația API-ului enumeră toate endpoint-urile; proiectul folosește ultimul tip.

Răspunsul începe cu un cod

Clasa codului arată unde e problema: în cerere (4xx) sau la server (5xx). Un 2xx înseamnă reușită, dar nu garantează date; corpul se verifică separat.

SimulareCinci situații tipice ale aceleiași cereri

Răspunsul are codul 429. Ce înseamnă?

429 înseamnă depășirea limitei de cereri. Se reia mai rar: după pauza din Retry-After, iar la colectări mari, cu pauze care cresc după fiecare refuz.
