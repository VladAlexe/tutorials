Lecția 3 din 8

Versionare și colaborare cu Git

La lecția anterioară am colectat date. Acum ne asigurăm că datele și codul care le-a colectat nu se pierd: Git, GitHub, lucrul în echipă și întrebarea de cercetare a proiectului.

Lecția se deschide după ce este predată la curs. Până atunci, descrierea de mai jos rămâne disponibilă.

Despre lecție

Ora are două părți, aparent fără legătură. În prima învățăm Git, adică modul în care un proiect își păstrează istoricul: cele trei zone între care se mută fișierele, depozitul local, legătura cu GitHub, ramurile și pull request-ul.

În a doua formulăm întrebarea de cercetare a proiectului, pornind de la proiectul cursului: cum se ajunge de la literatură la trei piloni (legăturile, oamenii, locul), de la piloni la surse de date și de la surse la întrebări care pot fi infirmate.

Legătura dintre ele: un proiect de analiză nu este o colecție de fișiere, ci un parcurs. Git păstrează parcursul, iar cadrul teoretic îi stabilește direcția. Fără primul, drumul până la rezultat nu poate fi reconstituit; fără al doilea, punctul de plecare nu poate fi justificat.

La finalul lecției vei putea

  • Să explici diferența dintre Git și GitHub și de ce un commit local nu este o copie de siguranță a muncii.
  • Să explici fiecare comandă prin zonele între care mută fișierele.
  • Să inițializezi un depozit, să îți setezi identitatea și să faci commit-uri cu mesaje informative.
  • Să scrii un .gitignore înainte de primul add și să explici de ce contează ordinea.
  • Să legi depozitul local de unul de pe GitHub sau să clonezi unul existent.
  • Să lucrezi pe ramuri, să deschizi un pull request și să rezolvi un conflict de îmbinare.
  • Să recunoști structura unui cadru teoretic: concept, sursă de date, rol în argument.
  • Să formulezi o întrebare de cercetare care poate fi infirmată cu datele disponibile.

Pregătire

Lecția poate fi urmărită fără programe instalate. Partea practică necesită ce a fost pregătit la cursul 2:

  1. Git, instalat. Pe Windows include Git Bash, un terminal în care funcționează comenzile din lecție.
  2. Contul de GitHub, același cu care intri pe site.
  3. Depozitul echipei, clonat la cursul 2 în dsw/proiect, și datele colectate în dsw/curs/data/c2.
