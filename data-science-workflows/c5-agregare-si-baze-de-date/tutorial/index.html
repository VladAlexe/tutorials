02 · Baza de date

Cinci copii sau un singur loc

Întrebarea „de la câte rânduri este nevoie de o bază de date” este formulată greșit: dimensiunea este rareori motivul. Pandas lucrează fără dificultate cu milioane de rânduri, iar datele proiectului sunt mult sub acest volum. Motivul real este ordinea: toate tabelele într-un singur loc, cu o singură versiune, din care citește oricine lucrează pe date.

03 · Baza de date

Unde stă o bază de date

O bază de date relațională ține datele în tabele, interogate cu SQL. Aceleași tabele și aceleași interogări pot sta în trei locuri, care diferă prin cine are acces și cine întreține baza.

la seminar

Într-un fișier

SQLite

sqlite:///data/dsw.db
  • fără server, cont sau parolă
  • un singur fișier, ușor de mutat
  • un singur scriitor odată
în instituții

Pe un server

PostgreSQL, MySQL

postgresql://utilizator:parola@server/baza
  • mulți utilizatori deodată
  • acces cu utilizator și parolă
  • cineva întreține serverul
găzduit

În cloud

Neon, Supabase, Azure SQL

postgresql://...@ep-....neon.tech/neondb
  • același PostgreSQL, întreținut de firmă
  • pornește la cerere, se oprește singur
  • plan gratuit pentru proiecte mici

„SQLite nu concurează cu serverele de baze de date. SQLite concurează cu fopen().”sqlite.org, „Appropriate Uses For SQLite”

SQLite este o bază într-un singur fișier, inclusă în Python. Nu are server: programul citește și scrie direct fișierul. Este potrivită pentru analiză, pentru învățare și ca format de fișier pentru date; nu este potrivită când mulți utilizatori scriu în același timp, prin rețea.

PostgreSQL și MySQL sunt baze cu server: un program care rulează permanent și la care se conectează mai mulți utilizatori, fiecare cu contul și drepturile lui. Sunt cele mai folosite baze de date, alături de SQLite.

04 · Baza de date

O adresă, orice bază

create_engine, din SQLAlchemy, primește adresa bazei și întoarce o conexiune, numită de obicei engine. Pandas o folosește în ambele sensuri: to_sql scrie un tabel în bază, read_sql aduce rezultatul unei interogări ca tabel pandas.

Pentru SQLite, adresa este calea fișierului, față de dosarul caietului: sqlite:///data/dsw.db înseamnă fișierul dsw.db din curs/data/. Pentru o bază pe un server, adresa conține utilizatorul, parola și serverul:

sqlite://felul bazei/data/dsw.dbfișierul, față de caiet
postgresql://felul bazeiutilizatorutilizatorul:parolaparola: secretul@ep-....neon.techserverul/neondbbaza

O adresă cu parolă nu se scrie niciodată în caiet: se pune într-un fișier .env, exclus din Git prin .gitignore, și se citește cu python-dotenv. Baza SQLite a cursului nu are parolă, deci acest pas nu este necesar.

05 · Baza de date

Patru tabele, patru entități

O bază relațională ține fiecare lucru despre care există date, o entitate, într-un tabel separat. Fiecare tabel are o cheie: coloanele care identifică un rând, ca în C4. Tabelele se leagă prin coloane comune: regiune_1 din sci arată spre regiune din regiuni.

Tabelele se citesc din depozitul cursului, ca toți să aibă aceleași date, și se încarcă cu to_sql. Fișierele din data/processed rămân sursa; baza este locul din care se citește de acum înainte.

Exercițiu de codÎncărcarea

Baza își ține singură evidența tabelelor, într-un catalog care se interoghează ca orice tabel. În SQLite: select name from sqlite_master where type = 'table'; în PostgreSQL, catalogul se numește information_schema.tables.

Cum se unesc două tabele

Două tabele se unesc în două feluri. concat le pune unul sub altul, când au aceleași coloane: s-a folosit în C3. merge le alătură după o cheie comună, adăugând coloane: s-a folosit în C4. La unirea după cheie, tipul unirii hotărăște ce se întâmplă cu rândurile care nu își găsesc perechea.

În exemplu, CH02 nu are PIB în tabelul regiunilor, iar HU11 nu apare în perechi. inner le pierde pe amândouă, left o păstrează pe prima cu PIB lipsă, outer le păstrează pe amândouă.

Tabelul sci are 44.253 de perechi, iar fiecare regiune apare o singură dată în regiuni. Câte rânduri dă sci left join regiuni?

left join păstrează toate rândurile din stânga, iar cheia din dreapta este unică, deci fiecare pereche găsește cel mult un rând. Dacă cheia din dreapta s-ar repeta, rândurile s-ar înmulți.

left join regiuni r1 on p.regiune_1 = r1.regiune caută, pentru fiecare pereche, rândul din regiuni cu același cod. Este exact ce face merge în pandas, cu how="left". Culorile arată ce corespunde.

În caiet, aceeași unire se face și în pandas, cu toți cei șapte indicatori, iar tabelul rezultat, perechi_regiuni, se scrie în bază. 10 · Agregarea

De la 44.253 de rânduri la două

group by împarte rândurile în grupuri și calculează câte un rezultat pe grup: count(*) (câte rânduri), avg (media), sum (totalul), min, max. Orice coloană din select care nu este calculată trebuie să apară în group by.

Exploraregroup by, pas cu pas
select case when tara_1 = tara_2 then 'aceeasi tara' else 'tari diferite' end as tip,
       count(*) as perechi,
       avg(sci) as sci_mediu
from perechi_regiuni
group by tip

SCI-ul mediu este de 43 de ori mai mare în aceeași țară. Ce altceva diferă între cele două grupuri, în afară de graniță?

Perechile din aceeași țară sunt, în medie, mai apropiate, deci rezultatul amestecă granița cu distanța. La cursul 6, cele două se despart: comparația se face la aceeași distanță.

12 · Agregarea

Media regiunilor nu este media țării

Lituania are două regiuni NUTS2: Vilnius și împrejurimile, cu PIB-ul pe locuitor mare, și restul țării, cu mai mulți oameni. Lățimea fiecărui dreptunghi este populația, înălțimea este PIB-ul pe locuitor.

ExplorareLituania, două regiuni

Media unei variabile pe țară nu este media țării, pentru că regiunile au populații diferite. Când se agregă, întrebarea de pus întâi este ce reprezintă un rând: aici, o regiune, nu un om.

Vârsta medie a unei țări, calculată din vârstele medii ale regiunilor ei: ce mai trebuie știut?

Fiecare regiune cântărește cât populația ei. Înainte de orice agregare: ce reprezintă un rând?

13 · Agregarea

Migrația are direcție

Al treilea tabel de analiză are câte un rând pe pereche de țări: SCI, migrația și zborurile. Migrația are direcție: românii din Italia nu sunt același lucru cu italienii din România. Tabelul migrației se unește de două ori, câte o dată pentru fiecare sens, cu coloanele redenumite ca să se potrivească cu cheile perechii; apoi cele două sensuri se adună. Dacă un sens lipsește, suma rămâne lipsă.
