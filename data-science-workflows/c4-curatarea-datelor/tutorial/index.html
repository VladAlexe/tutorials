06 · Git în practică

Anulări

Git are reputația unui instrument dificil în mare parte pentru că oferă patru moduri de a anula o modificare, iar numele lor nu indică direct ce face fiecare.

PredicțieAnularea unui commit publicat
Regula generală

Dacă eroarea există doar în depozitul local, oricare dintre comenzi este acceptabilă. Dacă a ajuns pe GitHub și a fost preluată de alții, singura variantă sigură este revert.

Dacă Git deschide editorul Vim

La git merge sau la git commit fără -m, Git deschide un editor de text pentru mesaj. Dacă editorul implicit este Vim, terminalul pare blocat. Pentru a salva și a ieși: Esc, apoi :wq și Enter.

Pentru că nu produce un rezultat vizibil: după o oră de profilare, fișierul este neschimbat. Fără ea însă, deciziile ulterioare se iau fără temei, iar unele sunt ireversibile.

info() arată o coloană de prețuri ca object, nu ca număr. Ce înseamnă?

Pandas a găsit cel puțin o valoare pe care nu o poate interpreta ca număr: o virgulă zecimală, un spațiu, o cratimă „-” pusă în locul unei valori lipsă. O singură valoare nevalidă din zece mii este suficientă pentru ca întreaga coloană să fie citită ca text.

12 · Curățarea

Standardizarea codurilor

Când se combină două surse, aceeași țară poate avea coduri diferite. Eurostat folosește EL pentru Grecia și UK pentru Regatul Unit; Meta folosește codurile ISO, GR și GB. Pentru program sunt țări diferite, iar un join pe coduri le pierde fără niciun mesaj de eroare.

A doua capcană este mai greu de observat: Namibia are codul NA, iar pandas citește NA ca valoare lipsă. Rândurile Namibiei nu dispar, dar codul lor devine valoare lipsă, iar orice filtru sau join pe țară le pierde.

18 · Valori lipsă și extreme

Valorile extreme

Metoda clasică este regula intervalului intercuartilic: se calculează primul și al treilea cuartil, se ia diferența dintre ele și se marchează tot ce depășește Q3 plus de 1,5 ori această diferență.

q1 = d["sci"].quantile(0.25)
q3 = d["sci"].quantile(0.75)
iqr = q3 - q1
prag = q3 + 1.5 * iqr
extreme = d[d["sci"] > prag]

Factorul 1,5 este o convenție, nu o constantă derivată teoretic. Cu un prag mai jos apar mai multe „valori extreme”; cu unul suficient de sus, niciuna.

ExercițiuPe datele SCI
Distincția esențială

O valoare extremă este departe de restul distribuției. O valoare greșită este imposibilă. Prima se păstrează și se explică; a doua se corectează sau se elimină. Confuzia dintre ele poate duce la eliminarea tocmai a rezultatului relevant.

21 · Transformări

Două direcții, un rând

SCI-ul este simetric: o singură valoare pe pereche de țări. Migrația are direcție: un rând pentru românii din Italia, alt rând pentru italienii din România. Pentru a le reuni în același tabel, cele două direcții se aduc pe același rând prin două operații merge, câte una pentru fiecare direcție.

Pas cu pasRomânii din Italia și italienii din România
din_1_in_2 = migratie.rename(columns={"citizen": "tara_1", "geo": "tara_2", "persoane": "din_1_in_2"})
din_2_in_1 = migratie.rename(columns={"citizen": "tara_2", "geo": "tara_1", "persoane": "din_2_in_1"})

tari = tari.merge(din_1_in_2, on=["tara_1", "tara_2"], how="left")
tari = tari.merge(din_2_in_1, on=["tara_1", "tara_2"], how="left")
tari["migranti"] = tari["din_1_in_2"] + tari["din_2_in_1"]

Codul complet se află în caietul cursului 4. De reținut: cu how="left" se păstrează toate perechile din SCI, iar cele fără date de migrație rămân cu valoare lipsă. Suma a două coloane dă valoare lipsă dacă oricare dintre ele lipsește, ceea ce este comportamentul dorit.
