02 · Recapitulare

Git, pe scurt: lucrul zilnic pe dev

Lecția 3 a introdus depozitul echipei și ramura dev. De aici încolo, Git devine un obicei de lucru, nu un subiect separat: fiecare pas al proiectului se încheie cu un commit pe dev. Tabelul rezumă ciclul zilnic și adaugă cele trei anulări de care este nevoie cel mai des.

CândComenzileCe fac
la începutul lucruluigit switch dev ; git pullramura de lucru, la zi cu colegii
după un pas încheiatgit add fisier ; git commit -m "mesaj"pasul intră în istoric
imediat dupăgit pull ; git pushîntâi ce au trimis colegii, apoi trimiterea proprie
o modificare greșită, înainte de addgit restore fisierfișierul revine la ultimul commit
un add greșitgit restore --staged fisierfișierul iese din pregătire; modificarea rămâne
un commit greșit, deja publicatgit revert <cod>un commit nou care îl anulează; istoricul colegilor rămâne intact

Cele trei anulări lucrează la niveluri diferite. git restore și git restore --staged lucrează la nivel de fișier, înainte de commit. git revert lucrează la nivel de commit și este singura variantă sigură după publicare, pentru că adaugă un commit nou în loc să rescrie istoricul pe care colegii l-au preluat deja.

Caietul echipei a fost modificat din greșeală, iar git add nu a fost încă rulat. Ce comandă readuce versiunea din ultimul commit?

git restore aduce fișierul la starea din ultimul commit. Varianta cu --staged doar îl scoate din pregătire, revert lucrează cu commit-uri, nu cu fișiere, iar git rm l-ar scoate din depozit.

05 · Cursul

Curățarea și integrarea datelor

Preprocesarea (C3) a adus sursele la o structură comună: coloanele necesare, denumiri consecvente, unitatea de analiză corectă. Curățarea pune o întrebare diferită: dacă valorile din această structură sunt corecte, complete și comparabile între surse. La final, sursele curățate dau primul tabel de analiză, cel al regiunilor; integrarea tuturor surselor, în perechi de regiuni și de țări, urmează în C5.

Etapele urmează o ordine stabilă, pentru că fiecare presupune rezultatele celei anterioare: profilarea precede orice decizie, codurile se aliniază înainte de unire, iar validarea încheie procesul. Tabelul leagă fiecare etapă de secțiunea caietului în care este aplicată.

Cât timp ocupă curățarea

O estimare citată frecvent (CrowdFlower, 2016) atribuie curățării și organizării datelor aproximativ 60% din timpul unui proiect. Cifra provine dintr-un sondaj comercial, nu dintr-un studiu riguros, și trebuie citită ca ordin de mărime: curățarea ocupă o parte importantă a muncii, iar deciziile luate acum determină validitatea tuturor rezultatelor ulterioare.

06 · Profilarea

Prima privire asupra unui tabel

Primele întrebări puse unui tabel nou sunt descriptive: cât de mare este, ce coloane are, cum arată primele și ultimele rânduri și câte valori distincte are fiecare coloană. Metodele de mai jos nu modifică tabelul; ele se pot rula oricând, de oricâte ori, și sunt primul lucru de făcut după fiecare citire sau unire.

MetodaCe aratăPe datele cursului
shape(rânduri, coloane); atribut, fără paranteze(2281, 3)
columnsnumele coloanelorregiune, valoare, indicator
head(), tail()primele, ultimele 5 rânduri (sau câte cerem)BE10 … RS22
describe()minim, medie, cuartile, maxim pe coloanele numericeo populație minimă de 0
nunique()câte valori distincte are fiecare coloană385 de regiuni, 7 indicatori
unique()care sunt valorile distinctenumele celor 7 indicatori
value_counts(normalize=True)proporții în loc de număr de rândurivarsta_medie 0,155
indicatori.shape                  # (2281, 3)
indicatori.head()                 # primele 5 rânduri
indicatori.nunique()              # regiune 385, valoare 1282, indicator 7
nume.describe(include="object")  # 1.971 coduri distincte, dar doar 1.879 nume

describe() lucrează implicit pe coloanele numerice. Cu include="object" descrie coloanele text: câte valori sunt, câte sunt distincte, care apare cel mai des. Pe nomenclatorul nume, codurile sunt toate diferite (1.971), dar numele nu: „Kýpros” apare de 4 ori, o dată pe fiecare nivel, de la țară până la NUTS 3. De aceea tabelele se unesc după coduri, niciodată după nume.

Atribut sau metodă

shape și columns sunt atribute: proprietăți ale tabelului, scrise fără paranteze. head(), describe() sunt metode: operații, scrise cu paranteze, care pot primi argumente (head(10)).

08 · Profilarea

O funcție proprie, cu apply

Uneori regula de verificare nu există ca metodă gata făcută. Atunci regula se scrie ca funcție, cu def, și se aplică pe fiecare valoare a unei coloane cu apply. Exemplul verifică dacă coloana nivel din nomenclator e consecventă cu lungimea codurilor.

def nivel_din_cod(cod):
    return len(cod) - 2              # RO -> 0, RO1 -> 1, RO11 -> 2, RO113 -> 3

nume["nivel_calculat"] = nume["regiune"].apply(nivel_din_cod)   # pe fiecare cod
(nume["nivel_calculat"] != nume["nivel"]).sum()                  # 0: se potrivesc toate

Rezultatul e 0: coloana e consecventă cu codurile și poate fi folosită în analiză. Când există o metodă directă, ea e mai simplă și mai rapidă decât apply; aici, nume["regiune"].str.len() - 2 dă același rezultat. Mai târziu, aceeași funcție se poate scrie pe un singur rând, cu lambda.

09 · Profilarea

Tipurile: numerele sunt numere?

Tipul unei coloane decide ce operații se pot face cu ea. În tabelul indicatorilor, valoare este float64 (număr cu zecimale, cu NaN pentru lipsuri), iar regiune și indicator sunt object, adică text.

Când printre numere apare un text, de exemplu :, cu care Eurostat marchează uneori o valoare indisponibilă, pandas citește toată coloana ca text, iar calculele nu mai funcționează. pd.to_numeric cu errors="coerce" transformă textul în numere, iar ce nu poate fi număr devine valoare lipsă:

exemplu = pd.Series(["12.5", ":", "7"])     # o coloană citită ca text
pd.to_numeric(exemplu, errors="coerce")      # 12.5, NaN, 7.0

Când toate valorile se pot converti, astype schimbă tipul direct. Dacă o singură valoare nu se poate converti, astype dă eroare; de aceea funcționează și ca verificare.

pd.Series(["2022", "2023", "2024"]).astype(int)   # 2022, 2023, 2024, ca numere întregi

info() arată o coloană de valori ca object, nu ca număr. Ce înseamnă?

Pandas a găsit cel puțin o valoare pe care nu o poate interpreta ca număr: : la Eurostat, o virgulă zecimală, un spațiu. O singură valoare de acest fel este suficientă pentru ca întreaga coloană să fie citită ca text; pd.to_numeric(..., errors="coerce") o transformă în valoare lipsă.

10 · Curățarea

Duplicatele: același rând de două ori

Un rând repetat înseamnă aceeași observație de două ori: orice sumă sau medie calculată ulterior o numără dublu. Pe un tabel mic se vede cum lucrează cele două metode:

MetodaCe face
duplicated()True pentru fiecare rând identic cu unul de deasupra lui, altfel False
sum()adunate, valorile True dau numărul de rânduri repetate
drop_duplicates()tabelul fără rândurile repetate: rămâne doar prima apariție
Exercițiu de codDuplicatele

Pe datele reale, verificarea se face pe cheie: coloanele care identifică un rând. În tabelul indicatorilor, cheia este regiune + indicator, iar indicatori.duplicated(["regiune", "indicator"]).sum() dă 0: nicio observație nu apare de două ori.

Există și o dublură pe care duplicated nu o vede: aceeași informație în două rânduri cu chei diferite. În SCI, fiecare pereche apare în ambele ordini, cu aceeași valoare:

regiune_1regiune_2sci
RO11ITC49.760Nord-Vest, Lombardia
ITC4RO119.760aceeași legătură, în ordine inversă

SCI nu are direcție, deci cele două rânduri sunt aceeași legătură. Dublura se rezolvă în C5, la integrarea perechilor, prin păstrarea unei singure ordini a fiecărei perechi.

11 · Curățarea

Valorile imposibile sau neobișnuite

Două categorii trebuie ținute separat. O valoare imposibilă încalcă o regulă logică: un procent peste 100, o populație negativă. Ea se corectează sau se elimină, iar decizia se notează. O valoare neobișnuită este doar departe de celelalte. Ea se verifică în sursă și, de cele mai multe ori, se păstrează: poate fi chiar fenomenul studiat.

VerificareaÎn caietRezultatul
rezumatul populațieipopulatie["valoare"].describe()un minim de 0
cele mai mici valoripopulatie.nsmallest(3, "valoare")NO0B, Svalbard
cele mai mari valoripopulatie.sort_values("valoare", ascending=False).head(3)Istanbul, Île-de-France, Lombardia
procentele(procente["valoare"] > 100).sum()0 valori peste 100

Populația minimă din tabel este 0, la regiunea NO0B. Ce se face cu acest rând?

NO0B este Svalbard, arhipelagul norvegian, iar Eurostat raportează efectiv 0. Valoarea este neobișnuită, dar nu greșită. Regula: o valoare neobișnuită se verifică în sursă; doar o valoare imposibilă (un procent de 140, o populație negativă) se corectează sau se elimină.

Valorile extreme statistice

Regulile statistice pentru valori extreme (de exemplu, pragul de 1,5 ori intervalul intercuartilic) țin de explorarea distribuțiilor, în C6. La curățare contează regulile logice formulate explicit.

12 · Lipsurile

Valorile lipsă

În pandas, o valoare lipsă se scrie NaN. Ea nu înseamnă zero: înseamnă că sursa nu are date pentru acea celulă. Primul pas este numărarea lor, pe fiecare coloană.

MetodaCe face
isna()True unde lipsește valoarea (NaN), altfel False
sum()adunate, valorile True dau numărul de valori lipsă
Exercițiu de codCâte valori lipsesc

Pe tabelul regiunilor, regiuni.isna().sum() dă numărul de lipsuri pe fiecare coloană, iar regiuni.isna().mean() proporția lor: rețelele sociale lipsesc la 42% dintre regiuni, ceilalți indicatori la sub 8%. La medie, pandas ignoră valorile lipsă; la o sumă de două coloane, o valoare lipsă dă rezultatul lipsă.

Un caz special: NA este Namibia

La citire, pandas transformă automat în valoare lipsă câteva texte, între care NA. În datele de migrație, NA este codul Namibiei, deci citirea implicită ar pierde 44 de rânduri fără niciun mesaj.

CitireaCodul NARânduri pierdute
pd.read_csv(fisier)devine NaN (lipsă)44 de rânduri cu Namibia
pd.read_csv(fisier, keep_default_na=False, na_values=[""])rămâne Namibia0
Pas cu pasNamibia și valorile lipsă

Tratamentul lipsurilor

Dacă lipsurile sunt puține și fără tipar, rândurile pot fi eliminate fără consecințe. Dacă au un tipar (anumite țări nu raportează un indicator), eliminarea lor schimbă compoziția datelor, iar completarea lor inventează valori. În acest caz, lipsa se păstrează și se documentează.

complete = regiuni.dropna()                          # 161 din 298 regiuni, 24 din 37 țări

pib = regiuni["pib_locuitor"]
completat = pib.fillna(pib.median())                 # 22 de regiuni primesc mediana
pib.std(), completat.std()                           # 14503, 13968

Eliminarea ar scoate aproape jumătate dintre regiuni și 13 țări întregi. Completarea cu mediana reduce abaterea standard: datele par mai omogene decât sunt, pentru că 22 de regiuni primesc aceeași valoare, inventată.

ExercițiuTratamentul potrivit fiecărui caz
Decizia adoptată

Toate cele 298 de regiuni se păstrează, fără completarea valorilor lipsă. Lipsurile se tratează abia la analiză și doar pentru coloanele folosite: regiuni.dropna(subset=["pib_locuitor", "somaj"]) păstrează 272 de regiuni, față de 161 cu dropna() pe toate coloanele. Tabelul salvat rămâne întreg.

13 · Curățarea

Aceeași țară, alt cod

Când se combină două surse, aceeași țară poate avea coduri diferite. Eurostat folosește EL pentru Grecia și UK pentru Regatul Unit, iar SCI folosește codurile ISO, GR și GB. Pentru program sunt țări diferite, iar o unire pe coduri le pierde fără niciun mesaj de eroare.

Regatul UnitGBUKla fel
MetodaCe face
replace(dicționar)înlocuiește valorile după un dicționar {vechi: nou}

În caiet, aceeași corecție se aplică pe coloanele migrației: migratie.replace({"tara_rezidenta": coduri, "cetatenie": coduri}).

În datele introduse de mână (chestionare, registre), aceeași categorie apare des în mai multe forme: cu spații, cu litere mici. Metodele din grupul .str le aduc la aceeași formă:

scrise = pd.Series([" RO", "ro", "Ro "])     # 3 valori distincte
scrise.str.strip().str.upper()                # RO, RO, RO
14 · Integrarea

Din lung în lat: un rând pe regiune

Tabelul indicatorilor este în format lung: un rând pe regiune și indicator. Formatul este potrivit pentru colectare și pentru verificări (un indicator nou înseamnă doar rânduri noi), dar analiza regiunilor cere un rând pe regiune, cu câte o coloană pe indicator: formatul lat. pivot face trecerea.

Pas cu pasDin lung în lat

În caiet, tabelul lat se lipește apoi de lista celor 298 de regiuni din SCI, cu how="left", ca să rămână și regiunile fără date. Numărul de rânduri se verifică imediat: 298 înainte, 298 după.
