Lecția 2 în lucru

Colectarea datelor prin API

Ce este un API, cum se citește o documentație, și cum aduci primele date reale în proiect.

Lecția se publică înainte de curs Caietul lecției
01

Ce va conține

Planul lecției. Conținutul interactiv, verificările și caietul se adaugă înainte de ședința din semestru.

  • Ce este un API și cum citești o documentație fără să o citești toată
  • Cereri HTTP: parametri, coduri de răspuns, limite de rată, ce faci când primești 429
  • API-ul Băncii Mondiale: structura tabulară, paginarea, și de ce rădăcina e un tablou
  • API-ul Eurostat: JSON-stat, dimensiuni, categorii și indexarea liniară a valorilor
  • Fișierele SCI de pe HDX: ce descarci, ce nu, și cum salvezi varianta brută
02

Ce adaugi la proiect

Primele date colectate prin API, salvate brut în date/brute/, plus scriptul care le aduce.

Lucrăm pe aceleași date tot semestrul: Social Connectedness Index, cu atribute aduse prin API de la Eurostat și Banca Mondială. Dacă vrei să te uiți peste surse din timp, sunt toate adunate în pagina cu sursele de date.

Pregătire

Până atunci, mergi mai departe cu lecția 1 și ține mediul de lucru pregătit.
