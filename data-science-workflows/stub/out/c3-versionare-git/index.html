Lecția 3 în lucru

Versionare cu Git

De ce versionăm, cum lucrează o echipă pe același proiect, și ce nu se urcă niciodată.

Lecția se publică înainte de curs
01

Ce va conține

Planul lecției. Conținutul interactiv, verificările și caietul se adaugă înainte de ședința din semestru.

  • De ce versionăm: istoric, reveniri, și lucrul în paralel fără să vă suprascrieți
  • commit, branch, merge: cele trei operații din care e făcut aproape tot
  • Depozitul de echipă pe GitHub și fluxul prin pull request
  • .gitignore: datele, mediul virtual și secretele nu se urcă niciodată
  • Conflicte: de ce apar, cum arată, și cum se rezolvă fără panică
02

Ce adaugi la proiect

Depozitul de echipă pe GitHub, cu structura convenită, .gitignore și a doua sursă de date.

Lucrăm pe aceleași date tot semestrul: Social Connectedness Index, cu atribute aduse prin API de la Eurostat și Banca Mondială. Dacă vrei să te uiți peste surse din timp, sunt toate.

Pregătire
