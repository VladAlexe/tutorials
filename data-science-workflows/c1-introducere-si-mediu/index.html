Lecția 1 din 8

Introducere și configurare

Proiectul semestrului, pașii unei analize de date și configurarea mediului de lucru: mediul virtual, tipurile de date, formatul JSON.

Lecția se deschide după ce este predată la curs. Până atunci, descrierea de mai jos rămâne disponibilă.

Înainte de prima oră

Contul GitHubContul este gratuit, se creează în câteva minute și este necesar pentru intrarea la oră.
  1. Contul se creează pe github.com/signup. Adresa de e-mail folosită ar trebui să rămână valabilă și după absolvire.
  2. Numele de utilizator ar trebui să fie potrivit pentru un CV. Numele rămâne asociat contului și apare în istoricul depozitului echipei.
  3. Adresa de e-mail se confirmă: GitHub trimite un cod de confirmare; contul devine activ după confirmare.
  4. La prima oră se scanează codul de pe ecran, se apasă „Intru cu GitHub” și se alege numele din lista grupei. Pasul se face o singură dată pe semestru.

Contul servește la autentificarea pe site, fără o parolă nouă. De la cursul 2 este folosit și pentru depozitul echipei, din organizația comună a cursului. Datele înregistrate sunt descrise în politica de confidențialitate.

Despre lecție

Prima oră prezintă cursul și pregătește lucrul pe date.

Prima parte descrie proiectul semestrului: datele lui, adică legăturile sociale dintre locuri măsurate prin SCI și migrația, echipele și pașii unei analize de date, de la întrebare la raport.

A doua parte tratează tipurile de date, formatul JSON și mediul de lucru: VS Code, Python și un mediu virtual, gata pentru cursul 2.

Obiectivele lecției

  • Pașii unui proiect de analiză de date și motivul pentru care procesul revine frecvent la etapele anterioare.
  • VS Code și Python instalate, cu autentificarea pe site prin contul GitHub.
  • Crearea unui mediu virtual și recunoașterea momentului în care este activ.
  • Tipurile de date din Python și erorile care apar când tipul nu este cel potrivit.
  • Alegerea tipului potrivit pentru o coloană dintr-o bază de date, cu justificarea alegerii.
  • Diferența dintre un fișier text și unul binar și informația pe care o pierde fiecare format.
  • Citirea unui răspuns JSON și scrierea căii de acces până la valoarea căutată.

Pregătire

Lecția poate fi parcursă fără programe instalate. Partea practică, din caiet, necesită două programe gratuite și folderul cursului:

  1. VS Code, editorul folosit tot semestrul, cu extensiile Python și Jupyter.
  2. Python 3.11 sau mai nou. La instalarea pe Windows se bifează „Add Python to PATH”.
Folderul cursuluiO arhivă de pe GitHub, cu Caietul 01, datele lui și lista pachetelor. Se descarcă o singură dată.
Descarcă arhiva ZIP
  1. Arhiva se dezarhivează, iar folderul obținut, -DSW2026-main, se redenumește dsw.
  2. Folderul se deschide în VS Code (File → Open Folder), apoi se deschide terminalul (Terminal → New Terminal).
  3. În terminal se creează mediul virtual, se activează și se instalează pachetele, o singură dată:
    Windows, PowerShell
    py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
    macOS, Terminal
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  4. În caiet se alege mediul: Select Kernel → Python Environments → .venv.

Erorile frecvente la activare și soluțiile lor sunt în manual. De la cursul 2 se descarcă doar caietul fiecărei lecții.
