Lecția 1 din 8

Introducere și configurare

Proiectul semestrului, pașii unei analize de date și configurarea mediului de lucru: mediul virtual, tipurile de date, formatul JSON.

Lecția se deschide după ce este predată la curs. Până atunci, descrierea de mai jos rămâne disponibilă.

Înainte de prima oră

Contul GitHubContul este gratuit, se creează în câteva minute și este necesar pentru intrarea la oră.
  1. Crearea contului, pe github.com/signup. Adresa de e-mail folosită ar trebui să rămână valabilă și după absolvire.
  2. Un nume de utilizator potrivit pentru un CV. Numele rămâne asociat contului și apare în istoricul depozitului echipei.
  3. Confirmarea adresei de e-mail. GitHub trimite un cod de confirmare; contul devine activ după confirmare.
  4. La prima oră se scanează codul de pe ecran, se apasă Intru cu GitHub și se alege numele din lista grupei. Pasul se face o singură dată pe semestru.

Contul servește la autentificarea pe site, fără o parolă nouă. De la cursul 2 este folosit și pentru depozitul echipei, din organizația comună a cursului. Datele înregistrate sunt descrise în politica de confidențialitate.

Despre lecție

Prima oră are două părți. Prima stabilește ce se construiește: proiectul semestrului, datele folosite, echipele și succesiunea completă a pașilor unei analize de date, de la definirea problemei până la raportare. A doua configurează mediul de lucru, astfel încât de la cursul următor lucrul cu datele să poată începe direct.

Între ele stau noțiunile pe care se sprijină restul cursului: tipurile de date în Python, în SQL și în fișierele spațiale; diferența dintre un fișier text și unul binar; formatul JSON, folosit de toate API-urile din curs.

Lecția începe cu o întrebare formulată pe datele reale ale cursului, la care intuiția nu oferă un răspuns, și cu o evaluare scurtă a cunoștințelor inițiale. Evaluarea nu se notează; rolul ei este să stabilească punctul de plecare.

Obiectivele lecției

  • Pașii unui proiect de analiză de date și motivul pentru care procesul revine frecvent la etapele anterioare.
  • VS Code și Python instalate, cu autentificarea pe site prin contul GitHub.
  • Crearea unui mediu virtual și recunoașterea momentului în care este activ.
  • Tipurile de date din Python și erorile care apar când tipul nu este cel potrivit.
  • Alegerea tipului potrivit pentru o coloană dintr-o bază de date, cu justificarea alegerii.
  • Diferența dintre un fișier text și unul binar și informația pe care o pierde fiecare format.
  • Citirea unui răspuns JSON și scrierea căii de acces până la valoarea căutată.

Pregătire

Lecția poate fi parcursă fără programe instalate. Partea practică, din caiet, necesită două programe gratuite și folderul cursului:

  1. VS Code, editorul folosit tot semestrul, cu extensiile Python și Jupyter.
  2. Python 3.11 sau mai nou. La instalarea pe Windows se bifează Add Python to PATH.
Folderul cursuluiCaietul 01, datele lui și lista pachetelor, într-o arhivă de pe GitHub. Se descarcă o singură dată.
↓ Descarcă arhiva ZIP a cursului
  1. Extragerea arhivei în locația dorită. Folderul obținut se numește -DSW2026-main și se redenumește dsw.
  2. Deschiderea folderului dsw în VS Code (File → Open Folder), apoi a terminalului: Terminal → New Terminal. Terminalul pornește în folderul dsw.
  3. Mediul virtual: crearea, activarea și instalarea pachetelor, o singură dată:
    Windows, PowerShell
    py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
    macOS, Terminal
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  4. În caiet se alege Select Kernel → Python Environments → .venv. Caietul 01 se află în curs/.

Dacă PowerShell blochează activarea cu o eroare despre execution policy, se rulează o dată Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser și se reia comanda. Arhiva se descarcă o singură dată: de la cursul 2 se descarcă doar caietul lecției, în dsw/curs/. Detalii în manual.
