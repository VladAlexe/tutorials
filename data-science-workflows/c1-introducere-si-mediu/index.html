Lecția 1 din 8

Introducere și configurare

Proiectul pe care îl construim tot semestrul, pașii prin care trece o analiză de date, și configurarea calculatorului tău: mediu virtual, tipuri de date, formatul JSON.

Lecția se deschide după ce o facem la oră. Până atunci poți citi ce urmează, mai jos.

Înainte de prima oră

Fă-ți un cont de GitHubCinci minute, gratuit. Fără el nu poți intra la oră.
  1. Intră pe github.com/signup. Folosește o adresă de e-mail pe care o păstrezi și după facultate.
  2. Alege un nume de utilizator pe care l-ai pune în CV. Rămâne cu tine: proiectul echipei va fi acolo, sub numele tău.
  3. Confirmă adresa de e-mail. GitHub îți trimite un cod; fără el contul nu e activ.
  4. La prima oră scanezi codul de pe ecran, apeși Intru cu GitHub și îți alegi numele din lista grupei. O singură dată, pentru tot semestrul.

De ce GitHub: cu el intri pe site, fără parolă nouă; tot cu el lucrați, de la cursul 3, în depozitul echipei. Ce se salvează despre tine scrie în politica de confidențialitate.

Despre

Prima oră are două jumătăți. În prima stabilim ce construim: proiectul semestrului, datele pe care le folosim, echipele, și harta completă a pașilor prin care trece o analiză de date, de la definirea problemei până la raportare. În a doua ne configurăm calculatoarele, ca data viitoare să putem începe direct cu datele.

Între ele stau noțiunile fără de care nimic din ce urmează nu are sens: tipurile de date, în Python, în SQL și în fișiere spațiale; diferența dintre un fișier text și unul binar; și formatul JSON, pe care îl vorbesc toate API-urile de la care vom cere date.

Lecția începe cu o întrebare la care nu se poate răspunde din intuiție, pusă pe datele noastre reale, și cu o evaluare scurtă a ceea ce știi deja. Nu se notează; e ca să știu de unde pornim.

La final vei putea

  • Să descrii pașii unui proiect de analiză de date și să spui de ce te întorci constant la etapele anterioare.
  • Să ai instalate VS Code și Python și să lucrezi pe site cu contul tău GitHub.
  • Să îți creezi un mediu de lucru virtual și să știi, dintr-o privire, când e activ.
  • Să recunoști tipurile de date din Python și să spui ce se strică atunci când sunt greșite.
  • Să alegi un tip potrivit pentru o coloană dintr-o bază de date, și să explici de ce.
  • Să deosebești un fișier text de unul binar, și să știi ce pierde fiecare format.
  • Să citești un răspuns JSON și să scrii drumul până la valoarea care te interesează.

De ce ai nevoie, înainte

Lecția se poate citi fără nimic instalat. Partea practică, din caiet, are nevoie de două programe, amândouă gratuite, și de folderul cursului:

  1. VS Code, editorul în care lucrăm tot semestrul, cu extensiile Python și Jupyter.
  2. Python 3.11 sau mai nou. La instalare, pe Windows, bifează Add Python to PATH.
Folderul cursului, o singură datăCaietul 01, datele lui și lista pachetelor, într-o arhivă de pe GitHub.
↓ Descarcă ZIP-ul cursului
  1. Dezarhivezi arhiva unde vrei pe calculator. Folderul obținut se numește -DSW2026-main: redenumește-l dsw.
  2. Deschizi dsw în VS Code (File → Open Folder), apoi terminalul: Terminal → New Terminal. Pornește deja în dsw.
  3. Creezi mediul virtual, îl activezi și instalezi pachetele, o singură dată:
    Windows, PowerShell
    py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
    macOS, Terminal
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  4. În caiet alegi Select Kernel → Python Environments → .venv. Caietul 01 e în curs/.

Dacă PowerShell refuză activarea, cu o eroare despre execution policy, rulezi o dată Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser și repeți. Arhiva se descarcă o singură dată: de la cursul 2 descarci doar caietul zilei, în dsw/curs/. Pe larg, în manual.
