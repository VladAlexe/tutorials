Lecția 1 din 8

Introducere și configurare

Proiectul la care lucrăm tot semestrul, pașii unei analize de date și configurarea mediului de lucru: mediul virtual, tipurile de date, formatul JSON.

Lecția se deschide după ce este predată la curs. Până atunci, descrierea de mai jos rămâne disponibilă.

Înainte de prima oră

Creează-ți un cont GitHubContul este gratuit și se creează în câteva minute. Este necesar pentru intrarea la oră.
  1. Accesează github.com/signup. Folosește o adresă de e-mail pe care o vei păstra și după absolvire.
  2. Alege un nume de utilizator potrivit pentru un CV. Numele rămâne asociat contului, iar proiectul echipei va apărea sub el.
  3. Confirmă adresa de e-mail. GitHub trimite un cod de confirmare; contul devine activ după confirmare.
  4. La prima oră scanezi codul de pe ecran, apeși Intru cu GitHub și îți alegi numele din lista grupei. Pasul se face o singură dată pe semestru.

De ce GitHub: contul servește la autentificarea pe site, fără o parolă nouă, iar de la cursul 3 este folosit pentru depozitul echipei. Datele înregistrate sunt descrise în politica de confidențialitate.

Despre lecție

Prima oră are două părți. În prima stabilim ce construim: proiectul semestrului, datele folosite, echipele și succesiunea completă a pașilor unei analize de date, de la definirea problemei până la raportare. În a doua configurăm mediul de lucru, astfel încât de la cursul următor să putem lucra direct cu datele.

Între ele stau noțiunile pe care se sprijină restul cursului: tipurile de date în Python, în SQL și în fișierele spațiale; diferența dintre un fișier text și unul binar; formatul JSON, folosit de toate API-urile de la care vom solicita date.

Lecția începe cu o întrebare formulată pe datele reale ale cursului, la care intuiția nu oferă un răspuns, și cu o evaluare scurtă a cunoștințelor inițiale. Evaluarea nu se notează; rolul ei este să stabilească punctul de plecare.

La finalul lecției vei putea

  • Să descrii pașii unui proiect de analiză de date și să explici de ce procesul revine frecvent la etapele anterioare.
  • Să ai instalate VS Code și Python și să te autentifici pe site cu contul GitHub.
  • Să creezi un mediu virtual și să recunoști când este activ.
  • Să recunoști tipurile de date din Python și să explici ce erori apar când tipul nu este cel potrivit.
  • Să alegi tipul potrivit pentru o coloană dintr-o bază de date și să justifici alegerea.
  • Să deosebești un fișier text de unul binar și să știi ce informație pierde fiecare format.
  • Să citești un răspuns JSON și să scrii calea de acces până la valoarea căutată.

Pregătire

Lecția poate fi parcursă fără programe instalate. Partea practică, din caiet, necesită două programe gratuite și folderul cursului:

  1. VS Code, editorul în care lucrăm tot semestrul, cu extensiile Python și Jupyter.
  2. Python 3.11 sau mai nou. La instalare, pe Windows, bifează Add Python to PATH.
Folderul cursuluiCaietul 01, datele lui și lista pachetelor, într-o arhivă de pe GitHub. Se descarcă o singură dată.

  1. Extragi conținutul arhivei în locația dorită. Folderul obținut se numește -DSW2026-main: redenumește-l dsw.
  2. Deschizi dsw în VS Code (File → Open Folder), apoi terminalul: Terminal → New Terminal. Terminalul pornește în folderul dsw.
  3. Creezi mediul virtual, îl activezi și instalezi pachetele, o singură dată:
    Windows, PowerShell
    py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
    macOS, Terminal
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  4. În caiet alegi Select Kernel → Python Environments → .venv. Caietul 01 e în curs/.

Dacă PowerShell blochează activarea cu o eroare despre execution policy, rulezi o dată Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser și reiei comanda. Arhiva se descarcă o singură dată: de la cursul 2 se descarcă doar caietul lecției, în dsw/curs/. Detalii în manual.
