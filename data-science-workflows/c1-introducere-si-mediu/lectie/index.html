Tipurile de date din Python

Tipul determină operațiile posibile: numerele se adună, textele se concatenează, listele se parcurg.

Valori simple

  • 178intnumăr întreg
  • 8.5floatnumăr real
  • "RO"strșir de caractere
  • Trueboolvaloare logică
  • NoneNoneTypelipsa valorii

Colecții

  • ["RO", "IT"]listlistă
  • (46.77, 23.59)tupletuplu
  • {"tara": "RO"}dictdicționar
  • {"RO", "HU"}setmulțime

În baza de date, tipul se declară

Valorile care nu corespund tipului sunt respinse. Alege tipul după valori.

Cât spațiu ocupă un număr întreg

SMALLINT2 octeți · până la 32.767
INT4 octeți · până la 2.147.483.647
BIGINT8 octeți · până la 9.223.372.036.854.775.807

Fiecare valoare din coloană ocupă atâția octeți, pe fiecare rând. Se alege cel mai mic tip în care încape cea mai mare valoare posibilă, nu cea mai mare valoare observată. La cele 1,8 milioane de rânduri din fișierul pe regiuni NUTS 3, diferența dintre INT și BIGINT e de 7,2 MB, doar pentru o coloană. Detaliile: tipurile numerice în PostgreSQL.

Mediul virtual, în folderul cursului

Python-ul și pachetele cursului, în dsw/.venv, separate de restul calculatorului.

1. Folderul

Descarci ZIP-ul cursului, îl dezarhivezi, îl redenumești dsw și îl deschizi în VS Code.

2. Mediul

În terminalul din VS Code, o singură dată:

py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

macOS: python3 -m venv .venv, apoi source .venv/bin/activate

3. Caietul

În caiet alegi Select Kernel → Python Environments → .venv. De acum, codul rulează cu pachetele cursului.
